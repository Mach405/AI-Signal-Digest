Searching live web listings

This page ships with sample data. To pull live listings from across the web, connect one or more sources below — each just needs an endpoint that returns JSON in the listing shape.

  • MachineFinder (John Deere) — official dealer inventory
  • TractorHouse / Machinery Pete — large dealer + auction network
  • Kubota dealer locator feeds — regional dealer inventory
  • Facebook Marketplace / Craigslist — requires a scraping proxy or paid API

Drop your backend URL into DATA_SOURCE_URL in app.js and the grid will render live results instead of samples. The fetch + render path is already wired up.
